# LMP layer documentation

This directory contains the English research-style layer documentation for LMP.

- `lmp_layers.tex`: LaTeX source with formulas and implementation references.
- `lmp_layers.pdf`: compiled PDF, when a LaTeX engine is available.

To rebuild the PDF locally:

```sh
cd docs
pdflatex lmp_layers.tex
pdflatex lmp_layers.tex
```
